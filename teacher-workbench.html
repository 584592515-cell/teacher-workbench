☁️ 云同步服务器设置

部署云端服务器后可填入地址，实现多设备实时同步。 留空则使用本地模式（电脑 EXE 正常，手机仅离线存储）。

💡 如何部署云服务器？
1. 将项目中的 cloud-server 文件夹上传到 Render.com（免费）
2. 部署后将获得的网址填入上方输入框
3. 电脑和手机即可通过云端实时同步
⚡ 离线模式 · 数据仅保存在本地

⚠️ 设备冲突

检测到另一台设备 未知设备 当前在线。

班主任工作台仅支持单设备登录。
• 点击「强制退出并接管」：另一台设备将被强制退出，其内容会自动保存到云端
• 点击「取消」：返回登录页，本次不登录

🔑 配置 GitHub Token

数据将通过 GitHub 仓库持久化，换设备登录也不会丢失。

① 前往 github.com/settings/tokens
② 点击 Generate new token (classic)
③ 勾选 repo 权限，生成后复制粘贴到下方

⚠️ 保存失败
